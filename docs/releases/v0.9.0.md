# v0.9.0: Codex tracking and stable activity bubbles

Pipsqueak now tracks local Codex conversations alongside Claude Code. This
release also includes the fixes developed since the 0.8.0 installers.

## Bubbles stay visible during large updates

A large Codex log update could remove a working chat's bubble for a fraction
of a second or for more than ten seconds. Removing it also dropped its live
desktop subscription and could leave a finished chat controlling the pet's
green colour. The bubble returned once log reading caught up.

Pipsqueak now keeps the last fully read state and its live subscription during
catch-up. It does not show intermediate completion events superseded later in
the same update. Real completion, archival and interruption still take effect.

## Also included since 0.8.0

- Separate cards for Codex and Claude Code conversations, including chats in
  the same project; agent and project filters and a pinned conversation.
- Passive Codex Desktop activity and approval tracking on Unix, with local
  session-log fallback; Codex CLI and Windows use local logs.
- Codex async question reminders survive continued work and turn completion.
  Answers or an explicit reminder dismissal clear them.
- Resumed Codex chats use their newest log, preventing an old interruption
  from replacing a newer result.
- Claude background work remains active while the known agent process lives;
  approved shell prompts clear promptly and dead Linux sessions retire.
- More accurate elapsed times and completion notifications, reduced idle
  animation work, and Linux focus and existing-startup-entry fixes.

## Verification

- Regression tests exercise a 10 MiB update across more than twelve seconds
  of simulated polls, plus real completion, archival, rewritten logs,
  question dismissal, narration preferences and inactivity timeout.
- Local JavaScript and Rust suites pass; the release workflow checks tests,
  formatting, Clippy and sprite consistency on Linux and Windows.
- Native Linux upgrade verified: the installed and running executable hashes
  match the new build, setup diagnostics pass, live Codex tracking reconnects,
  and working conversation cards are visible. Preferences, window position,
  existing launcher and login-startup entry are preserved. The overlay remains
  above other windows without taking keyboard focus on restart.

Windows interactive desktop behaviour, a fresh installation, package removal,
multi-monitor changes and macOS have not been rechecked for this release.
macOS installers are not supplied. The existing Linux and Windows installer
formats remain available; Linux packages are built on Ubuntu 22.04.
