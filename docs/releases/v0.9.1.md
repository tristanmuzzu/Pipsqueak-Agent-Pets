# v0.9.1: idle chats stay idle, and requests that need you stand out

## Idle chats no longer look busy

Claude desktop app mods can call tools inside every open chat, for example
to poll session status about every 20 seconds. Those calls fire the same
Claude Code hooks as the agent's own work, so Pipsqueak treated each one as
activity: idle chats showed as Working, a finished chat's Done disappeared,
and stuck cards stayed "running" for up to eleven minutes after the agent
had stopped.

Pipsqueak now ignores tool calls the host app makes for a plugin (their
`tool_use_id` starts with `toolu_plugin_`). The agent's own tool calls are
tracked exactly as before. This affects every platform where such mods are
installed, Windows included.

## Requests that need you stand out

- Orange cards and chips pulse while they are waiting for you.
- Every new request blinks the tray icon, even with completion blinks turned
  off. Do Not Disturb still silences it, and reduced motion stops the pulse.
- A blocking Codex approval now outranks an async question on the same chat.
- A Codex system error asks for your attention instead of passing silently.

## Verification

- A regression test proves host-made tool calls are ignored for PreToolUse,
  PostToolUse and PostToolUseFailure while agent calls are still classified.
- Local JavaScript and Rust suites pass; CI checks tests, formatting, Clippy
  and sprite consistency on Linux and Windows.
- Native Linux: the fixed build was installed and its running executable hash
  matched the new build. Idle chats stopped receiving updates, and the pet's
  chips dropped from seven to only the chats that were really running.

Windows interactive desktop behaviour, a fresh installation, package removal,
multi-monitor changes and macOS have not been rechecked for this release.
macOS installers are not supplied. Linux packages are built on Ubuntu 22.04.
